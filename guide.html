Préparer votre copie locale

  1. Installez R et RStudio. Quarto est nécessaire pour produire les documents à partir des fichiers .qmd.
  2. Téléchargez le dépôt complet, puis décompressez-le. Un fichier .qmd téléchargé seul ne contient pas les données nécessaires.
  3. Ouvrez 8248096-initiez-vous-a-R-pour-l-analyse-de-donnees.Rproj dans RStudio. Le dossier du projet devient votre répertoire de travail.
  4. Conservez data_raw, img et doc à leur place. Le nom technique du projet est conservé pour la compatibilité avec les exercices.

Les paquets utilisés dans les exemples sont dplyr, magick, readxl, rvest, stringr et writexl. Installez-les dans votre environnement R personnel selon les instructions du cours. Le paquet magick peut nécessiter des bibliothèques système selon votre ordinateur.

Suivre le cours dans l’ordre

  1. Prise en main de RStudio et bonnes pratiques : bonnes_pratiques.qmd, puis le guide du dossier doc.
  2. Import : 01_importez_donnees.qmd. Les exemples présentent volontairement un premier essai incomplet, puis sa correction ; exécutez les blocs progressivement.
  3. Modification : 02_modifez_donnees.qmd. Gardez la même session R après les imports, car les objets créés précédemment sont réutilisés.
  4. Export : 03_exportez_donnees.qmd. Les fichiers de sortie sont créés par vos commandes ; leur absence initiale est normale.

Ne lancez pas aveuglément tous les scripts dans une session vide. La compilation Quarto peut utiliser une session séparée : vérifiez les objets nécessaires avant de compiler un corrigé complet.

L’exercice de récupération de texte consulte un site externe. La réponse peut évoluer ou être indisponible. Ce résultat dépend du fournisseur et doit être contrôlé lors de votre exécution.
